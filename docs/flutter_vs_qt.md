# Основные отличия Flutter от Qt

## Язык программирования

Qt чаще используется с C++. Flutter использует Dart. Dart проще для быстрой разработки интерфейса: в нем есть сборка мусора, удобные коллекции, `async/await` и встроенная работа с JSON.

## Подход к интерфейсу

В Qt интерфейс строится через виджеты, формы, сигналы и слоты. Во Flutter интерфейс описывается декларативно: функция `build` возвращает дерево виджетов, а при изменении состояния вызывается `setState`.

Пример отличия:

- Qt: изменить свойство виджета напрямую.
- Flutter: изменить данные состояния и перестроить нужную часть интерфейса.

## Контейнеры данных

В задании упоминается `QVector`. Во Flutter прямой необходимости в таком классе нет, потому что стандартная библиотека Dart уже содержит `List`.

В этой работе:

- Qt-вариант: `QVector<Dish>`;
- Flutter-вариант: `List<Dish>`.

## Работа с JSON

В Qt обычно применяются `QFile`, `QJsonDocument`, `QJsonObject`, `QJsonArray`.

Во Flutter применяются:

- `File` из `dart:io`;
- `jsonEncode` и `jsonDecode` из `dart:convert`;
- пакет `file_picker` для выбора файла через системный диалог.

## Графическая отрисовка

В Qt для ручного рисования используется `QPainter`.

Во Flutter используется похожий подход:

- `CustomPainter`;
- `Canvas`;
- `Paint`;
- `TextPainter`.

В задании 2 прямоугольники классов и линии наследования рисуются вручную на `Canvas`.

## Сеть

В Qt для UDP обычно используется `QUdpSocket`.

Во Flutter используется `RawDatagramSocket` из `dart:io`. Он позволяет:

- привязаться к локальному порту;
- принимать datagram-пакеты;
- отправлять байты на указанный IP и порт.

## База данных

В Qt есть модуль Qt SQL. Во Flutter база подключается через пакет. В этой работе используется `sqlite3`.

Преимущество SQLite для курсовой работы: не нужно отдельно устанавливать сервер БД. База хранится в одном файле, а путь к нему можно передать параметром запуска.

## Кроссплатформенность

Qt и Flutter оба позволяют делать кроссплатформенные приложения. В этой работе выбран Flutter, потому что один и тот же интерфейс можно собрать под Windows и Android без отдельной переработки формы.

Основное отличие: Flutter рисует интерфейс своим движком, а не использует нативные виджеты операционной системы напрямую. Поэтому внешний вид приложения на разных платформах получается более одинаковым.
